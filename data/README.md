# data/ — Synthetic documents (Sprint 1)

All documents here are SYNTHETIC and FICTIONAL — Riyadh Trust Bank is not
a real bank. No real bank data, no real customer data, no copied documents.

## Folders

- `docs_src/` — the editable source of each document (Markdown). Edit the
  `.md` here, then regenerate the PDFs with `python scripts/generate_docs.py`.
- `docs/` — the 8 generated PDFs (3 pages each, English + Arabic summary):
  01 KYC Policy, 02 AML Policy, 03 SAMA Compliance Summary,
  04 Personal Loan Policy, 05 Account Opening Policy, 06 HR Leave Policy,
  07 Charges & Fees Schedule, 08 PDPL Data Privacy Summary.
- `chunks.jsonl` — section-aware chunks produced by the ingestion CLI.
- `docs_manifest.json` — document list used by GET /api/v1/documents.
- `vector_store/` — local file vector store (vectors.npz + meta.jsonl +
  embedding_config.json). Regenerated by `scripts/index_chunks.py`.
  NOT committed to git; included in the Sprint 1 zip so the demo works
  without re-indexing.

## Regenerate everything (from the project root)

```powershell
python scripts/generate_docs.py
cd backend
python -m app.services.ingestion --docs ../data/docs --out ../data/chunks.jsonl --manifest ../data/docs_manifest.json
python ../scripts/index_chunks.py
python ../scripts/search_test.py
```

Do not drop any real bank PDF here.
